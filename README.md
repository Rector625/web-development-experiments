# Web Development Experiments

A twelve-week progression from Git and static pages to a MERN application.

## Experiments

| Week | Project | Run |
|---|---|---|
| 1 | GitHub Pages starter | Open `week01-github-pages/index.html` |
| 2 | Personal portfolio | Open `week02-portfolio/index.html` |
| 3 | To-do list | Open `week03-todo/index.html` |
| 4 | SEO and accessibility | Open `week04-seo-accessibility/index.html` |
| 5 | Weather app | Serve `week05-weather` and enter a city; it uses Open-Meteo without an API key |
| 6 | Responsive blog | Open `week06-blog/index.html` |
| 7 | Notes SPA | Open `week07-notes-spa/index.html` |
| 8 | Books REST API | `cd week08-books-api && npm install && npm start` |
| 9 | JWT authentication API | `cd week09-auth-api && npm install && npm start` |
| 10 | Deployment guide | See `week10-deployment/README.md` |
| 11 | Optimization example | Open `week11-optimization/index.html` |
| 12 | MERN architecture | See `week12-mern/README.md` |

## Git workflow

```bash
git init
git add .
git commit -m "Add web development experiments"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/web-development-experiments.git
git push -u origin main
```

Do not commit real API keys, JWT secrets, or database credentials.
